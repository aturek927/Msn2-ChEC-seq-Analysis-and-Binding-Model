# Msn2-ChEC-seq-Analysis-and-Binding-Model
Repository containing the code to analyze Msn2 ChEC-seq data as well as to use an MWC model to model Msn2 target binding.

The code for ChEC-seq analysis is in the "Bioinformatic Analysis of Msn2" folder. This contains the bash script for running bowtie, the python code for converting the aligned reads to target promoters, and the juptyer notebook for analyzing the A-DNA dinucleotide content of target promoters. The python code uses custom modules that are contained in the folders within the "Bioinformatic Analysis of Msn2" folder.

The code for the Msn2 MWC binding model is in the "MWC Modeling and Fitting" folder. This contains the jupyter notebook with the model.
